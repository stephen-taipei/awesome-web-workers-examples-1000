Awesome Web Workers Examples 1000 是什麼？

它是一個整理 Web Workers 實作範例的專案，示範如何把計算、資料處理與高負載工作搬到背景執行緒。

這些範例可以學到什麼？

你可以看到 Dedicated Worker、Shared Worker、OffscreenCanvas 與多執行緒模式在瀏覽器裡的具體用法。

誰適合使用這個專案？

適合需要優化前端效能、學習 background processing、或想快速找 Web Workers 參考實作的開發者。
